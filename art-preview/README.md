# ตัวอย่างงานภาพเทียนเต้า

สร้างด้วย ImageGen ในตัว เมื่อ 9 กันยายน 2026 เพื่อให้ผู้ใช้ประเมินทิศทางภาพก่อนพัฒนาต่อ

- `river-town-v1.png`: ภาพแนวทางฉากโรงเตี๊ยมริมน้ำพร้อมผู้คน เป็นภาพนิ่งรวมทุกองค์ประกอบ
- `character-concepts-v1.png`: ตัวอย่างรูปลักษณ์ตัวละคร 8 แบบ ยังไม่ใช่ชุดแอนิเมชันหรือ sprite sheet ที่ตรวจขนาดช่องพร้อมใช้งาน

ทั้งสองภาพยังไม่ได้เชื่อมกับ Simulation ต้องแยกชั้นภาพ จัดสเกลตัวละคร และทำเฟรมการเคลื่อนไหวก่อนใช้ในฉากที่ NPC เดินได้จริง
