## ความหมายของตัวเลข (สำรับต่อปี แยกเด็ก/ผู้ใหญ่ — วัดคนละขั้น บวกกันไม่ได้)

- ขาดทางกายภาพ (`*_short`): ตอนแบ่งข้าว ความต้องการหลังกินจากครัวของครัวเรือน × (1 − ส่วนที่ได้) ส่วนที่ได้ = ข้าวที่ที่นั้นได้
  (ของที่นี่ + ที่ขนมา) ÷ ความต้องการของที่นั้น — ข้าวที่ไม่มี ก่อนจ่ายเงินและก่อนเสบียงติดตัว ไม่นับผู้เดินทาง
- ไม่มีคนจ่าย (`*_unpaid`): ข้าวที่ยุ้งฉางให้ได้ลบที่จ่ายแล้ว ก่อนการช่วยผู้ใหญ่ (ทำงานแลกข้าว ข้าวในคุก) และก่อนเสบียงติดตัว
- ไม่ได้กิน (`*_unmet`): ความต้องการ − ที่กินจริงหลังทุกทาง ≤ ขาดทางกายภาพ + ไม่มีคนจ่าย
- เหตุปล่อยตามด้วยขาด: ที่หนึ่งปล่อยคนลงไร่อย่างน้อยหนึ่งคนในรอบหนึ่ง = หนึ่งเหตุ นับว่า "ตามด้วยขาด" ถ้าที่นั้นขาดข้าวอย่างน้อย
  หนึ่งรอบภายใน 90 วันถัดไป นับเหตุละครั้งเดียว
- ± คือความคลาดเคลื่อนมาตรฐานของค่าเฉลี่ยผลต่างจับคู่ (ส่วนเบี่ยงเบน / √18)

## เครื่องมือรอยตาม

- `trace_child.py <repo> <seed> <variant>` — ประวัติรายรอบของเด็กทุกคนที่อดตาย แยกขาดทางกายภาพ / ไม่มีคนจ่าย
- `trace_flows.py <repo> <seed> <cids> <wid:place;...> <วันเริ่ม> <วันจบ>` — การจ่ายจากกระเป๋าครัวเรือนพร้อมเหตุที่ถูกปฏิเสธ
  และข้าวเข้าออกยุ้งฉางแยกตามขั้นของรอบ (เน่า ผลิต กินที่นี่ ขน แบ่ง ครัว ข้าวของผู้ตาย เพดาน) พร้อมรายชื่อคนลงไร่
- `gold_tier_scan.py <repo> <seed>` — รอบแรกที่บัญชีทองชั้นใดชั้นหนึ่งไม่ปิด
